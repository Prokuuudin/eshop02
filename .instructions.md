## Core Principles

### 1. Architecture First
- **Use RSC by default** — only `'use client'` for interactivity (forms, state, effects)
- **Server-side rendering** for SEO-critical content (blog, product descriptions, landing pages)
- **Zustand** for client state (cart, wishlist, auth, notifications)
- **TypeScript strict mode** — all implicit `any` forbidden

### 2. SEO is Non-Negotiable
- Every page **must have** `generateMetadata` with:
  - Canonical URL (via `getSiteUrl()`)
  - `og:image` (fallback to `/og-default.jpg`)
  - `description` (120-160 chars)
  - `htmlLang` (from cookies or detect server-side)
- No CSR-only content (crawlers see empty pages)
- Schema.org structured data for every page type

### 3. Multilingual (ru/en/lv)
- Use `useTranslation()` hook (client) or `useLocaleHelpers()` (server)
- **Detect language** from: cookies → Accept-Language header → default ru
- Set `<html lang={lang}>` dynamically, not hardcoded
- Add `hreflang` tags for all language versions

### 4. Type Safety
```typescript
// REQUIRED for all user-facing data
export type Product = {
  id: string
  sku?: string  // optional for backward compat
  title: string
  description?: string  // 150+ words for SEO
  technicalSpecs?: Record<string, string>
}

// FORBIDDEN: implicit any
// ❌ export const handler = (data) => { }
// ✅ export const handler = (data: unknown): string => { }
```

### 5. Brand Consistency
- **One brand name everywhere:** "HairShop.lv" (not "Eshop", "BeautyShop", or "HairShop")
- **Legal entity:** SIA Miks Plus
- **Address:** Rencenu 10A, Riga, Latvia

## Development Workflow

### 1. Create New Page
```tsx
// app/feature/page.tsx
import { Metadata } from 'next'
import { getSiteUrl } from '@/lib/site-url'
import { getLanguageFromCookies } from '@/lib/locale-helpers'

export async function generateMetadata(): Promise<Metadata> {
  const siteUrl = getSiteUrl()
  const lang = getLanguageFromCookies()
  
  return {
    title: 'My Page',
    description: 'Description here (120-160 chars)',
    alternates: {
      languages: {
        ru: `${siteUrl}/ru/feature`,
        en: `${siteUrl}/en/feature`,
        lv: `${siteUrl}/lv/feature`,
      }
    },
    openGraph: {
      title: 'My Page',
      description: 'Description',
      images: [{ url: `${siteUrl}/og-default.jpg`, width: 1200, height: 630 }],
    }
  }
}

export default async function FeaturePage() {
  return (
    <main>
      <h1>My Page</h1>
      {/* Use server components by default */}
    </main>
  )
}
```

## Common Patterns

### Fetch Data in RSC
```tsx
// ✅ CORRECT
export default async function Page() {
  const products = await fetch(getSiteUrl() + '/api/products', {
    next: { revalidate: 3600 }  // ISR
  }).then(r => r.json())
  
  return <>{/* render */}</>
}

// ❌ WRONG
export default function Page() {
  const [products, setProducts] = useState([])
  useEffect(() => {
    fetch('/api/products').then(r => r.json()).then(setProducts)
  }, [])  // ← CSR, no SEO
}
```

### Handle Forms (Client Island)
```tsx
// app/contact/form.tsx (client component)
'use client'
import { useState } from 'react'

export function ContactForm() {
  const [email, setEmail] = useState('')
  
  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault()
    await fetch('/api/contact', {
      method: 'POST',
      body: JSON.stringify({ email })
    })
  }
  
  return <form onSubmit={handleSubmit}>{/* ... */}</form>
}

// app/contact/page.tsx (RSC wrapper)
export const metadata = { /* ... */ }

export default async function ContactPage() {
  return (
    <main>
      <h1>Contact</h1>
      <ContactForm />  {/* ← minimal client footprint */}
    </main>
  )
}
```

### Zustand Store (Persistent)
```tsx
// lib/my-store.ts
import { create } from 'zustand'
import { persist } from 'zustand/middleware'

interface MyStore {
  count: number
  increment: () => void
}

export const useMyStore = create<MyStore>()(
  persist(
    (set) => ({
      count: 0,
      increment: () => set((state) => ({ count: state.count + 1 }))
    }),
    {
      name: 'my-store',  // localStorage key
      partialize: (state) => ({ count: state.count })  // optional: selective persistence
    }
  )
)
```

## FAQ for Contributors

**Q: Should this be a client component?**  
A: Only if it uses hooks (useState, useEffect, onClick). If it's just rendering data → RSC.

**Q: How do I add a new language?**  
A: Edit `lib/i18n-context.tsx`, add language code to `SupportedLanguage` type, update cookie detection.

**Q: My page isn't in the sitemap**  
A: Edit `app/sitemap.ts` and add it. Use `generateStaticParams` for dynamic routes.

**Q: How do I see who can access this page?**  
A: Check `AdminGate`, `AuthGateDialog`, or middleware. Look for `useAuthStore()` to see platformRole requirements.

**Q: SEO isn't improving after my changes**  
A: 1) Check og:image exists 2) Verify canonical URL in DevTools 3) Test in Google's Rich Results Tester 4) Wait 2-4 weeks for crawl
